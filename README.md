# Future Focus Staff Portal

A Vite + React recreation of the Future Focus intranet dashboard concept.

## Open in VS Code
1. Unzip this project.
2. Open the `future-focus-intranet` folder in VS Code.
3. Open the VS Code terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL Vite shows in the terminal (usually `http://localhost:5173`).

## Main files
- `src/main.jsx` — dashboard content/components
- `src/styles.css` — complete design and responsive styling
- `public/` — local images used by the dashboard
